# MRM

Companion code and notebooks for a Substack series on **model risk management** —
building interpretable models, validating them, and finding where they fail.

The repository is organized into two tracks:

| Directory | Track |
|---|---|
| [`Tabular/`](Tabular/) | Interpretable modeling, diagnostics, and weakness detection for tabular data. |
| [`AI-Agent/`](AI-Agent/) | Validation and risk management for LLM / agentic systems. |

Each article lives in its own subdirectory with a short write-up and a
`notebooks/` folder holding the runnable companion notebook(s).
